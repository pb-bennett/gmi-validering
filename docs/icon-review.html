GMI Validator — Ikongjennomgang

Sammenlign ikonene som brukes i dag med forslag fra Phosphor Regular. Dette er en beslutningshjelp; forslag endrer ikke applikasjonen.

Ikoner/symboler som ikke inngår i standardisering
  • GMI-logo / BrandWordmark: godkjent produktidentitet; bevar godkjent asset, geometri og tilgjengelig navn.
  • GIS feature- og legendesymboler: koder geografiske objekter og tematiske kategorier, ikke generiske handlinger.
  • Diagram- og datavisualisering: chart marks og metrikksymboler representerer data.
  • QR: generert kode og logooverlegg må beholde lesbarhet og skannbarhet.
  • 3D geometri/materialmarkører: skiller sceneobjekter, materialer og geometrityper.
  • Terreng-, varsel-, pumpe- og domenesymboler: kan endre faglig mening dersom de byttes generisk.
  • Andre betydningsbærende analysebilder: stjerne/highlight, profil-, høyde-, validerings- og topplokmarkører beholdes til faglig vurdering.

Tilgjengelighetsopplysninger er kildeinspeksjon av synlig tekst, aria-label, title og aria-hidden. Verktøyet sertifiserer ikke runtime-atferd. Vurderinger lagres i denne nettleserens localStorage.
